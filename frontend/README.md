# EcoTrack Frontend Dashboard

Scientific, AI-driven Environmental Impact Monitoring System interface built with React, Vite, and Tailwind CSS.

## Architecture

- **Theme**: Professional scientific dashboard with white surfaces (`#ffffff`), forest green (`#1b4332`), teal (`#0f766e`), and charcoal (`#1e293b`).
- **Telemetry Feeds**: Open-Meteo Atmospheric Chemistry API, Central Pollution Control Board (CPCB) NAAQS standards, and WHO potability metrics.
- **Visualizations**: Responsive Recharts components with high-contrast accessibility.
- **Production Compliance**: Favicon, Privacy Policy, Terms and Conditions, and Domain/HTTPS verification workbench.

## Development

```bash
npm install
npm run dev
```
